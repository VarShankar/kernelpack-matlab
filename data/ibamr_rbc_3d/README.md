# IBAMR biconcave-membrane trajectory

The 3D fluid--structure trajectory used by
`examples/moving_surface_adr_tp_rbc_capstone.m` is distributed in the
repository's `data-v1` release asset. Run
`download_rbc_capstone_data.m` to download it, verify its SHA-256
checksum, and place it at `data/ibamr_rbc_3d/trajectory`. The trajectory was
generated by the external IBAMR 0.19 application in `examples/ibamr_rbc_3d`
with the committed `input3d` file.

The dataset contains 401 frames spanning 2000 IBAMR steps from `t=0` to `t=2`.
Each frame stores the positions and no-slip velocities of all 2562 material
markers. `material.csv` and `faces.csv` provide fixed material coordinates and
connectivity, while `diagnostics.csv` records area, volume, edge lengths, and
the membrane centroid.

The final relative area and volume changes are `8.2867e-6` and `-9.7472e-5`,
respectively. These diagnostics are generated by the FSI application and are
independent of the subsequent MATLAB surface transport calculation.

The release asset also contains the saved capstone table and MATLAB result used
by the redraw-only visualization pathway.
